# SQL Restaurant & Consumer Analysis

## 📌 Project Overview

This project focuses on analyzing **restaurant and consumer data using SQL**. The main goal is to understand consumer preferences, restaurant ratings, cuisines, spending patterns, and other useful business insights.

The project uses **MySQL** to clean, analyze, and extract meaningful information from the available datasets.

## 🎯 Objectives

- Analyze consumer preferences and behavior.
- Identify popular cuisines.
- Analyze restaurant ratings and performance.
- Understand consumer spending patterns.
- Find useful relationships between restaurants and consumers.
- Answer business questions using SQL queries.
- Generate meaningful insights from the data.

## 🛠️ Tools & Technologies

- **MySQL** – Database creation and SQL analysis
- **SQL** – Data querying and analysis
- **Microsoft Excel / CSV** – Dataset storage
- **PowerPoint** – Project presentation
- **GitHub** – Project documentation and version control
